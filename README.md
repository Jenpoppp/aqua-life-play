# Aqua Life Story — play build

The playable build of Aqua Life Story (cozy aquarium life-sim), for family and friends to try on a phone or computer
browser. Open the GitHub Pages link; the game saves in your own browser on your own device (no account, no cloud save yet).

This repository holds only the built game (`index.html` + `music/`). The source lives in a private repository.
